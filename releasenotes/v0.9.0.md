# v0.9.0 — 2026-09-19

> **사용성 릴리스.** 기능은 v0.8.2 그대로이고 화면·문구·설명을 처음 쓰는 사람 눈으로 다시 만들었습니다 — 알고리즘·레시피 값·출력·골든은 바뀌지 않습니다. 근거는 현재 GUI 5탭 감사 + Blender 툴팁 가이드·VS Code 설정·Lightroom·Roboflow·Toss UX 라이팅 패턴. 전 과정 오프라인·로컬·CPU.

## 바뀐 것

- **용어와 라벨** — 화면 문구는 한국어 하나, 영어 이름·YAML 키는 툴팁 둘째 줄. 탭은 흐름 순서로 `① 결함 표시 → ② 결함 보관함 → ③ 미리보기 → ④ 일괄 생성 → ⑤ 검수`, 7단계는 `결함 고르기 · 크기·회전 · 위치 정하기 · 붙이기 · 색·밝기 맞추기 · 카메라 효과 · 정답 영역`. 은행→결함 보관함, 소스→결함 조각, 대상→바탕 이미지, 저신뢰→마스크 신뢰도 낮음, 폴백→대체 처리, skipped→건너뜀, 정리본→정리된 데이터셋, 실측 CSV→현장 측정값. "배치"가 Batch(일괄 생성)와 Placement(위치 정하기)로 갈렸습니다. CLI·YAML 키·사이드카는 그대로.
- **파라미터 도움말** — 카드 폼 라벨이 한국어+단위(`회전 (°)`), 툴팁 3줄(라벨·YAML 키 / 무엇을 하고 올리면·내리면 어떻게 되는지 / 영어·형식·범위). method 콤보도 한국어 표시명+요약. 같은 문장을 CLI에서 `anograft explain geometry.scale` · `explain blend:poisson` · `explain preset:dent-graft`, 전체 표는 **`PARAMS.md`**. 도움말이 없는 필드·method·프리셋은 테스트가 막습니다.
- **카드 폼** — 프리셋 값과 다른 행은 teal 라벨 + ↺ 되돌리기, 카드 헤더 `바뀜 n · ↺`. 자주 안 만지는 값은 **고급 옵션** 아래 접힘(펼침 기억). 세기·임계는 슬라이더(더블클릭 = 되돌리기). 색·밝기 맞추기/카메라 효과는 헤더 체크로 켜고 끕니다. 0.7.5부터 카드가 오른쪽에서 잘리던 레이아웃 문제도 고쳤습니다.
- **프리셋 갤러리** — 프리셋 옆 `고르기…`: 10개 프리셋을 제목·한 줄·이럴 때·피할 때·근거와 **지금 고른 바탕 이미지에 적용한 썸네일**로 비교하고 더블클릭으로 적용.
- **작업 흐름** — 탭 이름에 상태 배지(`② 결함 보관함 · 19`, `⑤ 검수 · 미검수 40`), 탭 바 오른쪽 `다음: … →`, 레시피가 없을 때 시작 체크리스트(된 단계는 ✓).
- **경고와 힌트** — 카드 경고+고치기 버튼, 재검증 오류, 검수 탭의 대비·조명 힌트가 한 모양(아이콘·문장·행동). 핵심 경고 3종(축척·마스크 신뢰도·빛 방향)은 "무엇이 · 왜 → 이렇게" 문장으로. 일괄 생성 로그에 같은 경고가 3번 찍히던 것을 1번으로. **대비 힌트**: 클래스별 합성 대비 중앙값이 실제의 절반 미만이면 "이 클래스만 relative-paste 로 갈라 보라"(검수 탭·리포트·`dataset report`).
- **테마·글자 크기** — 상단 ⚙: 라이트/다크, 글자 100/115/130 %(다음 실행 때 적용). 다크 보조 텍스트 대비를 4.5:1 이상으로.

## English

> **Usability release.** Features are those of v0.8.2; the screens, wording and explanations were remade from a first-time user's point of view — algorithms, recipe values, outputs and goldens are unchanged. Grounded in an audit of the five GUI tabs plus Blender's tooltip guidelines, VS Code settings, Lightroom, Roboflow and Toss UX-writing patterns. Fully offline, local, CPU-only.

## What changed

- **Terms and labels** — UI text is Korean only; English names and YAML keys live on the second tooltip line. Tabs follow the workflow `① Label → ② Bank → ③ Studio → ④ Batch → ⑤ Review`, the seven stages are verbs (pick defect · size/rotation · place · paste · match colour/brightness · camera effects · GT area). The Korean word for "batch" no longer doubles as "placement". CLI, YAML keys and sidecars are untouched.
- **Parameter help** — card labels in Korean with units, 3-line tooltips (label · YAML key / what it does and what raising or lowering changes / English · type · range); method combos show readable names with a summary. The same text from the CLI: `anograft explain geometry.scale`, `explain blend:poisson`, `explain preset:dent-graft`; the whole table is **`PARAMS.md`**. A test fails if any field, method or preset lacks help.
- **Card form** — rows that differ from the preset get a teal label and a ↺ reset, the header shows `changed n · ↺`; rarely touched values fold under **Advanced**; strengths/thresholds get sliders (double-click resets); harmonize/degrade have an on/off box. A layout bug that clipped the cards since 0.7.5 is fixed.
- **Preset gallery** — `Choose…` next to the preset: all ten presets as cards (title, one-liner, use for / avoid, evidence) with **thumbnails rendered on the currently selected target image**; double-click applies.
- **Workflow** — status badges in tab names, a `Next →` button, and a start checklist when no recipe is open.
- **Notices** — card warnings + fix button, validation errors and the review tab's contrast/lighting hints share one component; the three core warnings read "what · why → do this"; batch log no longer repeats warnings three times. **Contrast hint**: when a class's synthetic median contrast is below half of the real one, the review tab, report and `dataset report` suggest splitting that class onto `relative-paste`.
- **Theme and font size** — ⚙ in the top bar: light/dark and 100/115/130 % font scale (applied on next start); dark secondary text now meets 4.5:1.

## Notes

- README and release notes follow the new glossary; developer docs and CLI identifiers (`bank`, `source`, `targets`) keep the English names.
- Regenerate `PARAMS.md` with `anograft explain --out PARAMS.md` (a `>` redirect on Windows writes CRLF).
