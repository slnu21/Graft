# v0.6.0 — 2026-09-15

> **실데이터 보정** 릴리스. v0.5.0 을 경면 금속 원형 부품(토크스 소켓, 찍힘, 1400², NG 10 + OK 10)에 처음 적용하며 나온 **알려진 문제 10건**(`KNOWN-ISSUES.md`)을 전부 다룹니다 — 결함이 안 생기는 면에 배치되던 것, 미리보기에서 ROI 마스크가 깨지던 것, 박스→마스크 추정이 엉뚱한 곳을 잡아도 지표에 안 보이던 것, 조명 의존 결함이 ±180° 로 돌던 것, 태그·축척이 "있는데 못 쓰던" 것, GUI 가 기존 YOLO 라벨을 못 읽고 빈 화면으로 켜지던 것. 알고리즘을 새로 만들지 않고 **실무에서 막히는 지점**을 메웠습니다. 전 과정 오프라인·로컬·CPU. 2차 실데이터 적용은 아직입니다.

## 새로운 기능

- **ROI `annulus` + 프리셋 `annulus-graft`** — 원형 부품의 **가공 링 면에만** 결함을 놓습니다. 중심·반경을 대상마다 자동 검출하고 `r_inner`/`r_outer` 는 반경 비율(촬영마다 부품이 움직여도 링이 따라감). 배치 실패 사유에 `ROI 최대 폭 vs 패치 크기` 진단과 조치 힌트.
- **프리셋 `dent-graft`** — 찍힘·덴트처럼 **조명 의존 결함**용: 회전 ±15°·flip 끔·축척 0.9~1.1, 위치는 균등·방향은 결/접선에 정렬, poisson NORMAL, 조화 0.2. 기존 프리셋(±180°)은 스크래치·얼룩용으로 그대로. 프리셋 9종.
- **박스→마스크 타당성 점수** — 박스 추정 마스크마다 `confidence`(0..1)와 flags(low-contrast · box-edge · fragmented · saturated). `bank ls` 의 `lowconf` 열, `bank preview` 의 **빨간 테두리**, `run`/스튜디오 경고(추정의 절반이 넘으면 강화). 면적은 그럴듯한데 엉뚱한 곳을 잡는 실패가 이제 보입니다.
- **라벨 탭 YOLO 초안** — 이미지를 열 때 옆의 `labels/<stem>.txt`(+`data.yaml`)를 찾아 박스는 GrabCut 추정, 폴리곤은 채움으로 **마스크를 미리 채웁니다**(클래스별, 자동/수동). 손보고 저장하면 `manual:mixed`, 그대로면 임포터와 같은 `yolo-box:*`. 목록에 라벨 있는 이미지 `▸`.
- **라벨 탭 ROI 모드** — "저장 대상 → ROI 마스크": 정상 이미지에 결함이 생겨도 되는 면을 칠해 `<mask_dir>/<stem>.png` 로 저장(레시피 `placement.roi: {method: mask_dir, path: …}`). 열 때 같은 이름 ROI 를 불러옵니다.
- **`source.tags` 필터** — `pipeline.source.tags: {include: [prodA, prodC], exclude: [old]}` 로 임포트 `--tags` 를 합성 때 골라 씁니다(클래스는 그대로, 클래스 안의 풀만). `run --dry-run` 에 필터 후 소스 수.
- **스튜디오 카드 파라미터 편집기** — 7단계 카드마다 레시피 스키마에서 위젯이 자동 생성(숫자·범위·on/off·선택·경로·목록·null 토글). 잘못된 값은 카드 빨간 줄 + 되돌림. 배치 카드에 ROI 하위 스테이지(method 콤보 + 폼).
- **GUI 시작 안내** — 레시피 인자 없이 켜면 최근 레시피를 복원하고, 없으면 스튜디오에 ko/en 4단계 안내.

## 바뀐 것

- `mask_dir` ROI 마스크가 대상과 크기가 달라도(같은 비율) NEAREST 로 맞춥니다 — 스튜디오 1024 축소 미리보기에서 원본 크기 마스크가 그대로 동작. skipped 사유가 결과("ROI 없음")가 아니라 원인("roi: …")을 가리키고, 스튜디오 카드에 `⚠ <stage>: …` 로 표시됩니다.
- µm/px 축척 정합이 (일부라도) 꺼진 채 돌면 `run`·스튜디오 상태바·배치 로그에 한 줄 경고. `bank ls` 에 `no_um`·태그별 수.
- `import-yolo` 요약에 저신뢰 추정 수. 은행 메타에 `confidence`/`flags`(이전 은행은 없음 = 점수 없음).
- `recipe init --write` 가 상위 폴더를 만듭니다.

## 알려진 한계

- 실데이터 **2차** 적용(위 10건이 실제로 해결됐는지)은 아직 — 다음 세션. `diff` 12 · grabcut/otsu 기본 · `dilate_px` · `prefer` 기본 · GrabCut `work_px` 는 그때 확정.
- 박스→마스크 추정 **자체**는 그대로(GrabCut/Otsu). 저대비 경면 표면에서는 점수가 낮게 나오면 라벨 탭에서 다듬는 흐름 — SAM 은 v1.0.
- 복사·붙여넣기는 조명 의존 결함을 원리적으로 재현하지 못합니다(`dent-graft` 는 "틀린 그림을 만들지 않는" 보수적 설정). 확산 인페인팅은 v1.0.
- 은행 탭·검수 탭은 아직 자리만(v0.7). 학습 mAP 근거 없음.

## 처음 쓰는 법 (실데이터, 5분)

1. `anograft-0.6.0-win64.zip` 을 풀고 `anograft-gui.exe` 실행 → 안내가 뜹니다.
2. **라벨** 탭 → `폴더 열기` 로 `images/`(옆에 `labels/` 가 있으면 `▸` 표시 + 초안 자동 채움) → 초안을 브러시/지우개로 다듬고 클래스 확인 → 상단 **은행** 칸 → **Ctrl+S**.
3. 원형 부품이면 **스튜디오** 프리셋 `annulus-graft`(배치 카드에서 `r_inner`/`r_outer` 를 ROI 오버레이에 맞춤), 찍힘이면 `dent-graft`. 임의 형상 ROI 는 라벨 탭 **ROI 모드**로 그려 `mask_dir`.
4. **배치로 보내기** → **생성 시작**. 상태바의 경고(축척·저신뢰)를 한 번 읽어 보세요.

## English

> The **real-data correction** release. Applying v0.5.0 to a first industrial dataset (mirror-finish round metal part, dents, 1400², 10 NG + 10 OK) surfaced **10 known issues** (`KNOWN-ISSUES.md`); this release addresses all of them — defects placed on surfaces where they never occur, the ROI mask silently breaking in the preview, box→mask estimates picking the wrong region without any metric noticing, lighting-dependent defects rotated ±180°, tags and physical scale that existed but could not be used, and a GUI that ignored existing YOLO labels and started empty. No new algorithms — the practical gaps got filled. Fully offline, local, CPU-only. A second real-data pass is still pending.

## New

- **`annulus` ROI + `annulus-graft` preset** — put defects **only on the machined ring** of round parts. Centre/radius are detected per target, `r_inner`/`r_outer` are ratios (the ring follows the part between shots). Placement failures now report `ROI max width vs patch size` with a hint.
- **`dent-graft` preset** — for **lighting-dependent** defects (dents, dings): rotation ±15°, no flip, scale 0.9–1.1, uniform position with axis aligned to grain/tangent, poisson NORMAL, harmonize 0.2. Existing presets keep ±180° for scratches/stains. 9 presets.
- **Box→mask plausibility score** — every box-estimated mask gets `confidence` (0..1) and flags (low-contrast · box-edge · fragmented · saturated). `lowconf` column in `bank ls`, **red border** in `bank preview`, `run`/Studio warning (stronger when more than half of the estimates are low). Plausible-sized but wrong masks are now visible.
- **YOLO draft in the Label tab** — opening an image finds the neighbouring `labels/<stem>.txt` (+`data.yaml`) and **pre-fills the mask** (boxes → GrabCut estimate, polygons → fill; per class, auto or manual). Edited masks save as `manual:mixed`, untouched ones as `yolo-box:*` like the importer. Labelled images show `▸` in the list.
- **ROI mode in the Label tab** — "Save as → ROI mask": paint the allowed surface on a normal image and save to `<mask_dir>/<stem>.png` (recipe `placement.roi: {method: mask_dir, path: …}`); existing ROIs are loaded when you open the image.
- **`source.tags` filter** — `pipeline.source.tags: {include: [prodA, prodC], exclude: [old]}` selects bank sources by the tags you gave at import (classes unchanged, only the pool inside each class). `run --dry-run` shows the filtered counts.
- **Studio card parameter editor** — every stage card builds its widgets from the recipe schema (numbers, ranges, on/off, choices, paths, lists, null toggles). Invalid values show a red line and revert. The placement card carries the ROI sub-stage (method combo + form).
- **GUI start** — without a recipe argument the most recent recipe is restored; failing that, a ko/en 4-step guide appears in Studio.

## Changed

- A `mask_dir` ROI mask of a different size (same aspect) is resized with NEAREST — the full-size mask works in the 1024-px Studio preview. Skip reasons now name the cause (`roi: …`) rather than the effect ("no ROI"), and Studio cards show `⚠ <stage>: …`.
- When physical scaling (µm/px) is off for some or all sources, `run`, the Studio status bar and the batch log say so. `bank ls` shows `no_um` and per-tag counts.
- `import-yolo` reports low-confidence estimates. Bank metadata carries `confidence`/`flags` (older banks simply have none).
- `recipe init --write` creates parent folders.

## Known limitations

- The **second** real-data pass (do these fixes hold on the actual part?) is still to come; `diff` 12, grabcut/otsu default, `dilate_px`, `prefer` default and GrabCut `work_px` will be settled there.
- The box→mask estimator **itself** is unchanged (GrabCut/Otsu). On low-contrast mirror surfaces the score tells you to refine in the Label tab; SAM is v1.0.
- Copy-paste synthesis cannot truly reproduce lighting-dependent defects (`dent-graft` is a conservative "don't produce impossible pictures" setting). Diffusion inpainting is v1.0.
- Bank and Review tabs are still placeholders (v0.7). No training-mAP evidence yet.

## First run on real data (5 minutes)

1. Unzip `anograft-0.6.0-win64.zip`, start `anograft-gui.exe` — a guide appears.
2. **Label** tab → `Folder` → your `images/` (a sibling `labels/` shows `▸` and pre-fills the draft) → refine with brush/eraser, confirm the class → **Bank** field at the top → **Ctrl+S**.
3. Round part? Pick the `annulus-graft` preset in **Studio** (tune `r_inner`/`r_outer` on the placement card against the ROI overlay). Dents? `dent-graft`. Arbitrary ROI shapes: paint them in the Label tab's **ROI mode** and use `mask_dir`.
4. **Send to batch** → **Run**. Read the status-bar warnings (scale, low confidence) once.
