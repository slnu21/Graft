# v0.10.0 — 2026-09-25

> **웹 UI 릴리스.** 이제 `anograft serve` 한 줄이면 브라우저에서 **결함 보관함 · 결함 표시 · 미리보기 · 일괄 생성 · 검수** 다섯 화면이 전부 돕니다. 기존 창(PySide6 GUI)도 그대로 있습니다 — 이번 버전은 **둘을 함께 냅니다**. 합성 알고리즘·레시피 스키마·출력·골든은 바뀌지 않았습니다. 전 과정 오프라인·로컬·CPU이고 **런타임 의존성은 여전히 넷**(numpy · opencv-python-headless · pydantic · pyyaml)입니다 — 웹 서버는 파이썬 표준 라이브러리로만 돌고, node 는 빌드할 때만 필요합니다(설치해서 쓰는 사람은 node 를 몰라도 됩니다).

## 새로 생긴 것

- **`anograft serve` — 브라우저 UI** (127.0.0.1:8000 고정). 다섯 화면:
  - **결함 보관함** — 조각을 타일로 보고 클래스·태그·신뢰도로 거르고 지웁니다. 여는 순간 **평가셋(holdout) 누수**를 함께 알려 줍니다.
  - **결함 표시** — 결함 사진에 붓·지우개·다각형·자동 선택으로 마스크를 그려 보관함에 넣습니다. **그리기 연산은 전부 서버(파이썬)** 가 하므로 결과가 기존 창과 정확히 같습니다.
  - **미리보기** — 원본|합성 **A/B 와이프**, 정답 영역·붙일 수 있는 영역 오버레이, 바탕 이미지 목록, **프리셋 갤러리**(지금 바탕으로 합성한 썸네일), 7단계 **카드 편집**(라벨·설명·범위는 스키마에서 그대로), **시드 변형** 그리드, 레시피 저장.
  - **일괄 생성** — 출력 폴더·장수·시드·워커·출력 형식을 정하고 실행, 진행률·로그·완료 요약. 중지하면 **그때까지의 파일과 manifest 는 남습니다**. 끝나면 버튼 하나로 검수 화면으로 넘어갑니다.
  - **검수** — 모아 보기 그리드 + 키보드 판정(A 채택 · R 반려 · U 취소), 합성 vs 실제 분포, 대비·조명 힌트, 반려 뺀 **정리된 데이터셋**과 리포트.
- **평가셋 누수 방지** — 보관함 폴더에 `holdout.txt`(파일 이름 목록)를 두면 그 사진은 **보관함에 못 들어갑니다**(임포터·결함 표시 저장 모두). 이미 들어가 있으면 `bank ls`·`bank verify` 가 알려 줍니다 — 지우는 건 사람이 정합니다.
- **보관함 스냅샷** — `anograft bank snapshot <bank> --out snap.json` / `bank verify <bank> --snapshot snap.json`. **복사가 아니라 id + 내용 해시 목록**이라 라운드를 거듭해도 "그때 그 보관함인가"를 정확히 비교할 수 있습니다(없어짐 · 새로 들어옴 · 내용 바뀜).
- **학습기 계약** — `anograft trainer list · info · fit · predict`. 학습기는 **별도 venv 의 프로세스**로 부르므로(JSON 주고받기) 코어의 순수 wheel 원칙이 그대로입니다. 동봉 어댑터: `adapters/yolo.py`(ultralytics 검출), `adapters/anomalib_trainer.py`(PatchCore·PaDiM·FastFlow 등 **비지도** — 합성 결함을 학습에 넣지 않고 평가에만 씁니다), `adapters/noop.py`(표준 라이브러리만 — 학습기 없이 흐름을 시험할 때).

## 바뀐 것

- 기존 창(PySide6)은 **그대로 유지**됩니다. 웹과 같은 로직을 공유하도록 내부를 정리했을 뿐, 화면·동작은 v0.9.0 과 같습니다.
- `pip install anograft` 로 설치하면 웹 번들이 함께 깔립니다. 소스 체크아웃에는 번들이 없으므로(빌드 산출물은 저장소에 두지 않습니다) `anograft serve` 가 **죽지 않고 안내 페이지**를 보여 줍니다 — `cd web && npm ci && npm run build` 로 만들면 됩니다.

## 알아 둘 것

- 웹 UI 는 **127.0.0.1 고정**이고 `Host` 검사를 합니다. 값을 바꾸는 요청은 POST + 전용 헤더만 받습니다(다른 사이트가 열어 둔 서버를 건드리지 못하게).
- **미리보기는 긴 변 1024 축소본**입니다 — 배치 좌표·Poisson 결과가 원본 해상도와 다를 수 있어 화면에 축척을 늘 표시합니다. 정확한 결과는 일괄 생성(원본 해상도)에서 나옵니다.
- 한 번에 한 사람이 쓰는 로컬 도구를 전제로 합니다(서버가 세션 하나를 들고 있습니다).

## English

> **Web UI release.** A single `anograft serve` now opens all five screens in a browser — **defect bank, labeling, preview, batch generation and review**. The existing desktop window (PySide6) is still there: this version ships **both**. Synthesis algorithms, recipe schema, outputs and goldens are unchanged. Everything stays offline, local and CPU-only, and the runtime dependencies are still just four (numpy, opencv-python-headless, pydantic, pyyaml) — the web server is pure standard library, and node is needed only to build (users who install the package never see it).

## New

- **`anograft serve` — browser UI** (fixed to 127.0.0.1:8000), five screens:
  - **Defect bank** — browse crops as tiles, filter by class/tag/confidence, delete. Opening it also reports **hold-out leakage**.
  - **Labeling** — paint masks with brush, eraser, polygon and auto-select, then save into the bank. **All mask maths runs on the server (Python)**, so results match the desktop window exactly.
  - **Preview** — original|synthetic **A/B wipe**, GT and placeable-area overlays, target list, **preset gallery** (thumbnails synthesized on your current target), editable **7-stage cards** (labels, help and limits come straight from the schema), a **seed-variant** grid, and recipe saving.
  - **Batch** — set output folder, count, seed, workers and writer format, then run with progress, log and a final summary. Stopping keeps **what was already written, manifest included**; one button hands the output to the review screen.
  - **Review** — grid plus keyboard verdicts (A accept, R reject, U undo), synthetic vs real distributions, contrast and lighting hints, pruned dataset and report.
- **Hold-out protection** — put `holdout.txt` (a list of file names) in a bank folder and those photos **cannot enter the bank** (importers and labeling alike). If some are already in, `bank ls` and `bank verify` tell you; removing them stays your call.
- **Bank snapshots** — `anograft bank snapshot <bank> --out snap.json` and `bank verify <bank> --snapshot snap.json`. It is a **list of ids and content hashes, not a copy**, so you can tell across rounds whether the bank is the same one (missing · added · changed).
- **Trainer contract** — `anograft trainer list · info · fit · predict`. Trainers run as **processes in their own venv** (JSON in/out), so the core keeps its pure-wheel dependencies. Bundled adapters: `adapters/yolo.py` (ultralytics detection), `adapters/anomalib_trainer.py` (PatchCore, PaDiM, FastFlow… **unsupervised**, so synthetic defects are used for evaluation only), `adapters/noop.py` (standard library only, for testing the flow without a trainer).

## Changed

- The desktop window (PySide6) is **kept as is**. Internals were refactored so both UIs share the same logic; its screens and behaviour match v0.9.0.
- `pip install anograft` includes the web bundle. A source checkout has no bundle (build artifacts are not committed), so `anograft serve` **shows a short guide page instead of failing** — build it with `cd web && npm ci && npm run build`.

## Notes

- The web UI binds to **127.0.0.1 only** and checks the `Host` header; writes require POST plus a custom header, so another site cannot poke a server you left running.
- **Preview renders at 1024 px on the long edge**, so placement coordinates and Poisson results can differ from full resolution; the scale is always shown on screen. Exact results come from batch generation at full resolution.
- It assumes a single local user (the server holds one session).
