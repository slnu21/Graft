# v0.5.0 — 2026-09-15

> **GUI 만으로 단독 사용**이 되는 첫 버전입니다. 결함 **사진**만 있으면 라벨 탭에서 마스크를 그려 은행을 만들고, 스튜디오에서 미리 보고, 배치 탭에서 데이터셋을 생성합니다 — CLI 도 라벨링 도구도 필요 없습니다. 여전히 **샘플 데이터로만 검증**했고 실데이터·학습 1 epoch 은 미검증입니다. 전 과정 오프라인·로컬·CPU.

## 새로운 기능

- **라벨 탭** — 폴더를 열고 사진을 고른 뒤 **브러시**(B)·**지우개**(E)·**폴리곤**(P)·**자동 선택**(A: 결함 둘레로 박스를 끌면 GrabCut/Otsu 로 마스크 추정)으로 마스크를 만듭니다. 팽창/침식, 되돌리기 40단계, 마스크 PNG 불러오기. 클래스(은행에 있는 이름은 목록에서)·픽셀 피치·태그를 적고 **은행에 저장**(Ctrl+S) — 떨어진 조각은 소스 여러 개로(원하면 하나로). 저장하면 마스크가 비워져 같은 사진의 다음 결함을 바로 이어 라벨링합니다. 스튜디오가 같은 은행을 쓰고 있으면 저장 즉시 미리보기에 반영됩니다.
- **배치 탭** — 스튜디오의 **배치로 보내기**가 현재 레시피를 넘깁니다(저장하지 않아도 됨). 출력 폴더·장수·시드·워커·출력 형식(yolo / pairs / mvtec)을 고치고 **생성 시작** → 진행률·로그·**중지**(그때까지의 파일과 manifest 는 남습니다)·출력 폴더 열기. 결과는 `anograft run` 과 바이트 동일하고, 로그 첫 줄에 같은 CLI 명령이 남습니다.

## 바뀐 것

- 스튜디오 "배치로 보내기"가 클립보드 복사에서 배치 탭 전환으로(명령도 여전히 복사됩니다).
- 배치 실행이 중간에 멈추면 사이드카·manifest 에 그때까지의 결과가 남고 요약에 "취소됨"이 표시됩니다.

## 알려진 한계

- 실데이터·MVTec AD/VisA 실제 사본·anomalib/ultralytics 학습은 미검증(샘플로만).
- 은행에 저장한 소스를 GUI 에서 다시 열어 고치거나 지우는 기능은 없습니다(은행 탭, v0.7) — 잘못 저장했으면 `bank/<클래스>/<id>.*` 세 파일을 지우세요.
- 4K 사진에서 브러시는 부드럽지만 자동 선택(GrabCut)은 박스 크기에 따라 1–3초 걸립니다.
- 검수 탭은 아직 자리만 있습니다(v0.7).

## 처음 쓰는 법 (5분)

1. [Releases](https://github.com/slnu21/Graft/releases) 에서 `anograft-0.5.0-win64.zip` 을 풀고 `anograft-gui.exe` 실행.
2. **라벨** 탭 → `폴더 열기` 로 결함 사진 폴더 → 사진 클릭 → `A` 키 후 결함 둘레로 박스 드래그(또는 `B` 로 칠하기) → 클래스 입력 → 상단 **은행** 칸에 새 폴더 이름(예: `bank/mine`) → **Ctrl+S**. 사진마다 반복.
3. **스튜디오** 탭 → 은행 `bank/mine` · 대상 = 정상 사진 폴더 → **열기** → 프리셋(기본 poisson-graft)·시드로 미리보기 → 마음에 들면 **배치로 보내기**.
4. **배치** 탭 → 출력 폴더·장수 → **생성 시작**. `images/`·`masks/`·`meta/`·`manifest.csv` + `labels/`·`data.yaml`(YOLO) 이 생깁니다.

## English

> First version that is **usable from the GUI alone**. With nothing but defect **photos** you draw masks in the Label tab to build a bank, preview in Studio, and generate a dataset in the Batch tab — no CLI, no separate labelling tool. Still **verified on the bundled sample set only**; real data and a training epoch are unverified. Fully offline, local, CPU-only.

## New

- **Label tab** — open a folder, pick a photo, then **brush** (B), **eraser** (E), **polygon** (P) or **auto-select** (A: drag a box around the defect → GrabCut/Otsu mask estimate). Dilate/erode, 40-step undo, load a mask PNG. Enter the class (existing bank classes are listed), pixel pitch and tags, then **Save to bank** (Ctrl+S) — disconnected pieces become separate sources (or one, if you prefer). Saving clears the mask so you can label the next defect on the same photo right away. If Studio uses the same bank, the preview picks the new source up immediately.
- **Batch tab** — **Send to batch** in Studio hands over the current recipe (no save needed). Adjust output folder, count, seed, workers and output format (yolo / pairs / mvtec), press **Run** → progress, log, **Stop** (files and manifest written so far are kept), open output folder. Output is byte-identical to `anograft run`; the first log line is the equivalent CLI command.

## Changed

- Studio's "Send to batch" now switches to the Batch tab instead of only copying a command (the command is still copied).
- A batch stopped midway keeps its sidecars/manifest and the summary says "cancelled".

## Known limitations

- Unverified on real data, actual MVTec AD/VisA copies, and anomalib/ultralytics training (sample set only).
- No GUI to reopen, edit or delete a saved bank source yet (Bank tab, v0.7) — delete the three files `bank/<class>/<id>.*` by hand.
- On 4K photos brushing is smooth, but auto-select (GrabCut) takes 1–3 s depending on the box size.
- The Review tab is still a placeholder (v0.7).

## First run (5 minutes)

1. Unzip `anograft-0.5.0-win64.zip` from [Releases](https://github.com/slnu21/Graft/releases) and start `anograft-gui.exe`.
2. **Label** tab → `Folder` → choose the defect-photo folder → click a photo → press `A` and drag a box around the defect (or `B` to paint) → type the class → put a new folder name (e.g. `bank/mine`) in the **Bank** field at the top → **Ctrl+S**. Repeat per photo.
3. **Studio** tab → bank `bank/mine`, targets = your normal-photo folder → **Open** → pick a preset (default poisson-graft) and seed → when it looks right, **Send to batch**.
4. **Batch** tab → output folder and count → **Run**. You get `images/`, `masks/`, `meta/`, `manifest.csv` plus `labels/` and `data.yaml` (YOLO).
