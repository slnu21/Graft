# v0.7.2 — 2026-09-16

> v0.7.1 뒤의 **흐름 다듬기** 패치 — 배치 → 검수 한 번에, 저신뢰 소스 차례로 다듬기, 대비 분포, 스튜디오 µm/px, `anograft doctor`. 포맷·스키마 변경 없음. 전 과정 오프라인·로컬·CPU.

## 새로운 기능

- **배치 → 검수**: 배치가 끝나면 **검수 탭에서 열기** 버튼으로 바로 판정 화면으로. 검수 탭에 **다음 미검수 (N)**.
- **저신뢰 소스 차례로 다듬기**: 은행 탭 **저신뢰 전부 차례로 다듬기** → 라벨 탭에서 하나씩 다듬고 **다음 저신뢰 소스** — 저장한 소스는 목록에서 빠집니다.
- **대비(contrast) 분포**: 검수 탭 분포에 "대비" — 합성 결함의 마스크−링 그레이 차이를 실제(은행) 소스와 나란히(조화가 톤을 얼마나 옅게 했는지). 리포트에도 세 번째 히스토그램.
- **스튜디오 대상 µm/px** 입력(입력 패널) — 은행 피치와 함께 축척 정합을 GUI 에서 켭니다.
- **`anograft doctor [--json]`** — 환경 진단(버전·OpenCV 스레드·Qt·프리셋·불가 method). 문제 보고 첫 줄. **`bank ls --json`**.
- 스튜디오 변형 카드에 **저신뢰 소스 ⚠**(툴팁에 소스 id) · 라벨 탭 자동 선택 뒤 **confidence** 안내.

## English

> A **workflow polish** patch after v0.7.1 — batch → review in one click, refine low-confidence sources one after another, contrast distribution, target µm/px in Studio, `anograft doctor`. No data-format or recipe-schema changes. Fully offline, local, CPU-only.

## New

- **Batch → Review**: when a batch finishes, **Open in Review** takes you straight to verdicts. **Next unreviewed (N)** in the Review tab.
- **Refine low-confidence sources in sequence**: **Refine all low** in the Bank tab → refine one in the Label tab → **Next low-confidence source** — saved sources drop out of the list.
- **Contrast distribution**: a "contrast" histogram in the Review tab — mask-minus-ring gray difference of synthetic defects next to the real (bank) sources (how much harmonization faded the tone). Also in the report.
- **Target µm/px in Studio** (inputs panel) — turn on physical scaling from the GUI together with the bank's pitch.
- **`anograft doctor [--json]`** — environment diagnostics (versions, OpenCV threads, Qt, presets, unusable methods); first line of any bug report. **`bank ls --json`**.
- **Low-confidence source ⚠** on Studio variant cards (tooltip lists source ids) · **confidence** hint after auto-select in the Label tab.
