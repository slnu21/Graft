# v0.7.0 — 2026-09-16

> **GUI 5탭이 전부 실물**이 되는 버전입니다 — 은행 탭(소스 보기·삭제·다듬기)과 검수 탭(채택/반려·실제 vs 합성 분포·정리본)이 들어왔고, COCO writer 와 DTD 텍스처 안내가 붙었습니다. 흐름은 이제 **라벨 → 은행 → 스튜디오 → 배치 → 검수 → 정리본**으로 GUI 안에서 끝납니다. 전 과정 오프라인·로컬·CPU. 실데이터 2차 적용·학습 mAP 근거는 여전히 없습니다.

## 새로운 기능

- **은행 탭** — 은행을 열어 소스를 타일로 봅니다(마스크 윤곽, 추정 마스크는 amber, **저신뢰는 빨간 테두리**). 클래스·태그·저신뢰만·추정만·검색으로 거르고 id/신뢰도/면적/클래스로 정렬. 상세에 크롭+마스크 확대와 메타(flags 포함). **삭제**(세 파일 — class id 는 그대로라 이미 만든 `data.yaml` 과 어긋나지 않음)와 **라벨 탭에서 다듬기**(마스크를 고쳐 같은 id 에 덮어쓰기 — 손본 소스는 `manual:*`, 추정 점수는 지워짐). 은행이 바뀌면 스튜디오 미리보기가 다시 준비됩니다.
- **검수 탭** — `run`/배치 출력 폴더를 열어 합성 결과를 썸네일(GT 윤곽)로 보고 **A 채택 / R 반려 / U 보류**(`review.csv` 자동 저장, 다중 선택, 메모). 필터(미검수·채택·반려·폴백·skipped·클래스). 왼쪽 **분포 히스토그램**: 합성 결함(반려 제외)의 면적/긴 변 vs 은행 실제 소스 — 합성이 실제 분포에서 벗어나는지 한눈에. **정리본 내보내기** = 반려를 뺀 사본(정상 유지, manifest·`annotations.json` 정리). CLI `anograft dataset prune <out> --out <pruned>`.
- **COCO writer** — `output.writer: {format: coco}` → `annotations.json`(images·categories·annotations: 폴리곤 segmentation·bbox·area). Detectron2·mmdetection 용. 순수 JSON, 같은 레시피·시드면 같은 바이트.
- **DTD 텍스처** — `anograft dataset info dtd` 안내 + `anograft dataset textures dtd <dtd> --out textures.txt` 로 `perlin-texture`(DRAEM) 용 목록을 만듭니다(결함처럼 보이는 15 카테고리 기본, `--categories '*'` 로 전부). `texture_dir` 에 폴더 대신 `.txt` 목록을 줄 수 있습니다. 은행에는 넣지 않습니다.

## 바뀐 것

- 레시피를 열면 은행 탭도 그 은행을 엽니다. 배치가 끝나면 검수 탭 경로가 그 출력을 가리킵니다(열기는 버튼).
- 배치 탭 출력 형식에 `coco`.
- v0.6.0 CI 실패 1건(카드 경로 필드가 POSIX 에서 백슬래시를 유지) 수정.

## 알려진 한계

- 실데이터 2차 적용(v0.6 의 10건 보정이 실제로 통했는지)과 학습 mAP 비교는 아직 — 다음 사용자 작업.
- 검수 탭의 "실제" 분포는 은행 소스 마스크입니다(별도 실측 CSV 아님). 은행 경로가 상대경로면 GUI 를 다른 폴더에서 열었을 때 실제 막대가 비어 있습니다(제목에 "은행 없음").
- 검수 썸네일은 정본 이미지를 읽어 만듭니다 — 4K 100장은 첫 열기에 몇 초.
- COCO 는 폴리곤만(RLE 없음) — 구멍 있는 마스크는 바깥 윤곽만.
- 은행 탭 삭제는 되돌릴 수 없습니다(확인 대화상자 한 번).

## 처음 쓰는 법 (5분, v0.7 흐름)

1. `anograft-0.7.0-win64.zip` 을 풀고 `anograft-gui.exe` 실행.
2. **라벨** 탭에서 결함 사진 → 마스크 → 은행 저장(기존 YOLO 라벨이 있으면 초안이 자동으로 채워집니다).
3. **은행** 탭에서 저신뢰 소스를 걸러 **라벨 탭에서 다듬기** 또는 삭제.
4. **스튜디오**에서 프리셋·미리보기 → **배치로 보내기** → 생성.
5. **검수** 탭에서 A/R 로 판정 → 히스토그램으로 크기 분포 확인 → **정리본 내보내기** → 학습셋으로.

## English

> The version where **all five GUI tabs are real** — the Bank tab (browse, delete, refine sources) and the Review tab (accept/reject, real-vs-synthetic distribution, pruned export) arrive, plus a COCO writer and DTD texture guidance. The flow is now **Label → Bank → Studio → Batch → Review → pruned set**, entirely inside the GUI. Fully offline, local, CPU-only. A second real-data pass and training-mAP evidence are still pending.

## New

- **Bank tab** — open a bank and browse sources as tiles (mask contour; estimated masks amber, **low-confidence with a red border**). Filter by class, tag, low-confidence, estimated, search; sort by id/confidence/area/class. Detail view with an enlarged crop + mask and metadata (flags). **Delete** (three files — class ids stay put, so existing `data.yaml` files remain valid) and **Refine in Label** (fix the mask and overwrite the same id — refined sources become `manual:*` and lose their estimate score). Studio re-prepares when the bank changes.
- **Review tab** — open a `run`/batch output folder, browse results as thumbnails (GT contour) and press **A accept / R reject / U unreview** (`review.csv` auto-saved, multi-select, notes). Filters (unreviewed, accepted, rejected, fallback, skipped, class). A **distribution histogram** on the left: synthetic defects (rejects excluded) vs real bank sources by area / long side — spot synthetic sizes that drift from the real distribution. **Export pruned** = a copy without the rejects (normals kept, manifest and `annotations.json` rewritten). CLI `anograft dataset prune <out> --out <pruned>`.
- **COCO writer** — `output.writer: {format: coco}` → `annotations.json` (images, categories, annotations with polygon segmentation, bbox, area) for Detectron2 / mmdetection. Plain JSON; same recipe + seed → same bytes.
- **DTD textures** — `anograft dataset info dtd` plus `anograft dataset textures dtd <dtd> --out textures.txt` builds a texture list for the `perlin-texture` (DRAEM) source (15 defect-like categories by default, `--categories '*'` for all). `texture_dir` accepts a `.txt` list as well as a folder. Never imported into a bank.

## Changed

- Opening a recipe also opens its bank in the Bank tab. When a batch finishes, the Review tab points at that output (open with the button).
- `coco` in the Batch tab's output formats.
- Fixed the one v0.6.0 CI failure (card path field kept backslashes on POSIX).

## Known limitations

- The second real-data pass (did the v0.6 fixes hold on the actual part?) and training-mAP comparison are still ahead.
- The Review tab's "real" distribution is the bank's source masks (not a separate measurement CSV). With a relative bank path, opening the GUI from another folder leaves the real bars empty (title says "no bank").
- Review thumbnails are built from the canonical images — 4K × 100 takes a few seconds on first open.
- COCO is polygon-only (no RLE) — masks with holes keep only the outer contour.
- Bank deletion is irreversible (one confirmation dialog).

## First run (5 minutes, the v0.7 flow)

1. Unzip `anograft-0.7.0-win64.zip`, start `anograft-gui.exe`.
2. **Label** tab: defect photos → masks → save to bank (existing YOLO labels pre-fill a draft).
3. **Bank** tab: filter low-confidence sources → **Refine in Label** or delete.
4. **Studio**: preset, preview → **Send to batch** → run.
5. **Review** tab: A/R verdicts → check the size histogram → **Export pruned** → into your training set.
