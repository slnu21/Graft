# v0.8.2 — 2026-09-19

> **결함 성격별 프리셋.** 한 은행 안에서도 결함마다 맞는 블렌딩이 다르다는 것을 공개 데이터(Magnetic Tile)로 확인하고, 그걸 그대로 쓸 수 있게 두 가지를 더했습니다 — 대비를 보존하는 조화 방법 `relative`(+ 프리셋 `relative-paste`)와 프리셋을 클래스 일부에만 적용하는 `recipe init --classes`. 기본값·기존 프리셋·골든·은행 결과는 그대로(새 프리셋·옵션만 추가). 전 과정 오프라인·로컬·CPU.

## 새로운 기능

- **`harmonize.relative`** + 프리셋 **`relative-paste`** — 노출 보정. 소스 패치의 링(결함 주변) 평균을 대상 링 평균에 맞추는 **오프셋만** 마스크 안에 더합니다. stats·Reinhard·histmatch 는 내부를 대상 링에 맞추므로 정의상 결함 대비를 (1−strength) 배로 옅게 만들고, hard-paste 그대로는 노출이 제각각인 대상에서 절반이 "배경보다 밝은 구멍"이 됩니다(합성 대비 중앙값 0). `relative` 는 결함의 *상대* 대비를 두고 노출 차이만 없앱니다 — Magnetic Tile blowhole 합성 대비 중앙값 poisson −17 · hard-paste 0 · **relative-paste −37**(실제 −48). `paste` 뒤에 쓰는 것(poisson 뒤엔 이중 보정), L 채널만, 마스크 밖 불변. `ring_px`(12) · `gain`(σ 비 배율, 기본 off).
- **`anograft recipe init --classes A B`** → `source.classes`. 프리셋을 은행의 일부 클래스에만 적용해 따로 돌리고 `dataset merge --dedupe-normals` 로 한 학습셋을 만드는 흐름: `init --classes blowhole --preset relative-paste` · `init --classes break crack --preset poisson-graft` → `run` × 2 → `merge`(같은 은행 = 같은 클래스 id, 정상 한 벌). 은행 없는 프리셋(self-cut·perlin)엔 거부.
- **`BENCHMARKS.md` §2 "결함 성격별 프리셋"** — Magnetic Tile 에서 한 프리셋(poisson)으로는 −0.02 였던 합성이, blowhole 만 `relative-paste` 로 갈라 merge 하니 mAP50 **0.460 → 0.605(+0.15, 학습 시드 3/3)**, blowhole 0.34 → 0.81 · break 는 poisson 이 낫고(0.47) crack 은 무차별. metal_nut(모든 클래스가 poisson 에서 이득)에선 갈라도 그대로(0.452 vs 0.448) — 갈라야 할 때를 알려 주는 것이 검수 탭 클래스별 대비 히스토그램. `tools/train_mvtec_map.py --class-presets blowhole=relative-paste break=poisson-graft crack=poisson-graft` 가 같은 흐름을 mAP 비교까지 자동으로(`--presets <preset>+dent:<cls>` 로 한 레시피 `per_class` 변형도).

## English

> **Presets per defect type.** Public data (Magnetic Tile) showed that classes in one bank can want different blending, so this release adds the two pieces to act on it — a contrast-preserving harmonization `relative` (+ preset `relative-paste`) and `recipe init --classes` to apply a preset to a subset of classes. Defaults, existing presets, goldens and bank outputs are unchanged (new preset and options only). Fully offline, local, CPU-only.

## New

- **`harmonize.relative`** + preset **`relative-paste`** — exposure compensation. Adds only the **offset** that maps the source patch's ring (around the defect) mean onto the target ring mean, inside the mask. stats/Reinhard/histmatch match the inside to the target ring and therefore fade the defect to (1−strength) by construction, while plain hard-paste on targets with varying exposure turns half the holes brighter than the background (median synthetic contrast 0). `relative` keeps the defect's *relative* contrast and removes only the exposure difference — Magnetic Tile blowhole median contrast: poisson −17 · hard-paste 0 · **relative-paste −37** (real −48). Use after `paste` (after poisson it double-corrects); L channel only; nothing outside the mask changes. `ring_px` (12), `gain` (σ-ratio scaling, off by default).
- **`anograft recipe init --classes A B`** → `source.classes`. Apply a preset to some classes of a bank, run each recipe, and merge with `dataset merge --dedupe-normals`: `init --classes blowhole --preset relative-paste` · `init --classes break crack --preset poisson-graft` → `run` × 2 → `merge` (same bank → same class ids; normals kept once). Refused for bank-free presets (self-cut, perlin).
- **`BENCHMARKS.md` §2 "presets per defect type"** — on Magnetic Tile a single preset (poisson) gave −0.02; splitting only blowhole onto `relative-paste` and merging gives mAP50 **0.460 → 0.605 (+0.15, 3/3 training seeds)**, blowhole 0.34 → 0.81; break prefers poisson (0.47) and crack is indifferent. On metal_nut (every class gains from poisson) splitting changes nothing (0.452 vs 0.448) — the review tab's per-class contrast histogram tells you when a split is needed. `tools/train_mvtec_map.py --class-presets blowhole=relative-paste break=poisson-graft crack=poisson-graft` automates the flow through the mAP comparison (`--presets <preset>+dent:<cls>` for the single-recipe `per_class` variant).
