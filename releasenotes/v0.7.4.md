# v0.7.4 — 2026-09-16

> v0.7.3 뒤의 **클래스별 기하 · 검수 정밀화** 패치 — 스크래치와 찍힘이 섞인 은행을 레시피 하나로(`geometry.per_class`), 어느 이미지의 조명이 뒤집혔는지 골라내는 필터, 은행·라벨·검수 어디서나 같은 조명 지표. 레시피 스키마는 옵션 추가만(하위 호환). 전 과정 오프라인·로컬·CPU.

## 새로운 기능

- **`geometry.per_class`** — 클래스별 `scale`·`rotate`·`flip` 오버라이드(준 필드만 덮어씀). 스크래치는 ±180°, 찍힘은 ±15°·flip 끔을 **레시피 하나**로. 오버라이드 없는 클래스는 바이트 동일. 사이드카 `geometry.per_class`.
  - `recipe init --dent-class <cls>` / **`--auto-dent`**(은행의 `lightR` ≥ 0.5 클래스를 자동으로) · 스튜디오 기하 카드 **▶ 조명 클래스만 ±15°·flip 끔** 버튼(경고가 있을 때만, 한 번에 적용) · 카드 아래 per_class 정보 줄 · 퀵스타트(GUI '샘플 데이터'·`sample --quickstart`)가 처음부터 써 준다.
- **검수 필터 '조명 뒤집힘 의심'** — 실제 클래스 방향이 뚜렷할 때(R ≥ 0.5, n ≥ 3) 거기서 90° 넘게 벗어난 인스턴스가 있는 이미지. 리포트에 목록. CLI `dataset prune --drop-flipped`. 샘플 pit 을 ±180° 로 합성하면 40장 중 33장이 걸린다.
- 검수 **'실제' 분포는 레시피가 뽑은 클래스만**(`source.classes` → `class_ratio`) — pit 만 합성한 출력을 은행의 스크래치와 비교하지 않음. 히스토그램 제목에 `실제 = pit`.
- `bank preview`·은행 탭 타일 오른쪽 위 **조명 방향 화살표**(밝은 쪽) · 라벨 탭 통계에 **조명 방향**(각도 + 8방향).
- 배치 탭 로그에 prepare 경고(축척·저신뢰·조명)와 **배치 가능성** 한 줄. 빈 상태 안내 ⓪ '샘플 데이터'.

## English

> A **per-class geometry & review precision** patch after v0.7.3 — one recipe for a bank that mixes scratches and dents (`geometry.per_class`), a filter that picks out the images whose lighting got flipped, and the same lighting metric in the bank, label and review views. Recipe schema: additive options only. Fully offline, local, CPU-only.

## New

- **`geometry.per_class`** — per-class `scale` / `rotate` / `flip` overrides (only the given fields). Scratches at ±180°, dents at ±15° with no flip, in **one recipe**; classes without an override are byte-identical. Sidecar `geometry.per_class`.
  - `recipe init --dent-class <cls>` / **`--auto-dent`** (picks the bank's `lightR` ≥ 0.5 classes) · Studio geometry card button **▶ dent classes only: ±15°, no flip** (shown only while the warning is up, applies in one click) · a per_class info line under the card · the quickstart (GUI **Sample…** / `sample --quickstart`) writes it from the start.
- **Review filter "flipped lighting"** — images with an instance whose lighting direction deviates > 90° from the real class direction (when that direction is clear: R ≥ 0.5, n ≥ 3). Listed in the report. CLI `dataset prune --drop-flipped`. Sample pits rotated ±180° trip it on 33 of 40 images.
- Review **"real" distributions follow the recipe's classes** (`source.classes` → `class_ratio`) — an output that only synthesizes pits is no longer compared against the bank's scratches. Histogram title shows `real = pit`.
- **Lighting-direction arrow** on `bank preview` / Bank-tab tiles (top right, points to the bright side) · **lighting direction** in the Label-tab stats (angle + 8-way word).
- Batch tab log shows prepare warnings (scale, low confidence, lighting) and a **placement feasibility** line. Empty-state hint ⓪ "Sample…".
- `KNOWN-ISSUES.md` gains a fill-in table for the second real-data pass.

## Changed

- README review-tab screenshot replaced (lighting histogram, flipped-lighting filter).
