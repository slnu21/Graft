# v0.7.1 — 2026-09-16

> v0.7.0 의 후속 패치 — **속도**(스튜디오 ROI 재계산 제거)·**경로**(레시피 상대경로 폴백)·**은행 병합**·**검수 리포트**·CI 강화. 데이터 포맷·레시피 스키마 변경 없음. 전 과정 오프라인·로컬·CPU.

## 새로운 기능

- **`anograft bank merge a b --out c [--rename old=new] [--tags a,b]`** — 제품별로 따로 만든 은행을 하나로. 소스 세 파일을 그대로 복사(크롭·마스크·추정 점수 보존), 클래스는 이름 기준 병합(기존 id 유지), 같은 이름은 `-dup<n>`.
- **검수 리포트** — 검수 탭 **리포트** 버튼 / `anograft dataset report <out>` → HTML 한 장(채택/반려/미검수, 합성 vs 실제 크기 히스토그램, 클래스별 인스턴스, 반려 목록, skipped 사유). 의존성 없음.
- 라벨 탭 **자동 선택 뒤 타당성 점수** — 상태줄에 `confidence 0.xx`, 0.5 미만이면 다듬으라는 안내.

## 바뀐 것

- **스튜디오가 훨씬 빨라짐** — 같은 대상의 ROI(특히 GrabCut)를 변형마다·카드 편집마다 다시 풀지 않습니다(대상당 1회, 결과는 바이트 동일). 1400² GrabCut 변형 2.7 s → 0.2 s.
- **레시피 상대경로** — `inputs.bank`·`inputs.targets`·`texture_dir`·`roi.path` 가 현재 폴더에 없으면 **레시피 파일 기준**으로 찾습니다(기존 사용법 그대로). 다른 폴더에서 GUI 를 열어 최근 레시피를 복원해도 은행이 열립니다.
- CI 가 설치된 wheel 로 CLI 한 바퀴(sample → import → run 워커 2/0 바이트 비교 → report → prune → train_smoke dry-run)를 Windows·Linux 에서 돕니다.

## 알려진 한계

## English

> Follow-up patch to v0.7.0 — **speed** (no more ROI recomputation in Studio), **paths** (recipe-relative fallback), **bank merge**, **review report**, stronger CI. No data-format or recipe-schema changes. Fully offline, local, CPU-only.

## New

- **`anograft bank merge a b --out c [--rename old=new] [--tags a,b]`** — merge per-product banks into one. Source files are copied as-is (crop, mask, estimate score kept); classes merge by name (existing ids unchanged); name clashes become `-dup<n>`.
- **Review report** — the **Report** button in the Review tab / `anograft dataset report <out>` → a single HTML page (accepted/rejected/unreviewed, synthetic-vs-real size histograms, per-class instances, rejected list, skip reasons). No extra dependencies.
- **Confidence after auto-select** in the Label tab — the status bar shows `confidence 0.xx`; below 0.5 it asks you to refine.

## Changed

- **Studio is much faster** — the ROI of a target (GrabCut especially) is no longer recomputed per variant or per card edit (once per target, byte-identical results). 1400² GrabCut variant 2.7 s → 0.2 s.
- **Recipe-relative paths** — `inputs.bank`, `inputs.targets`, `texture_dir`, `roi.path` fall back to the recipe file's folder when not found from the current directory (existing usage unchanged). Restoring the most recent recipe from another folder now opens its bank.
- CI runs a CLI round trip on the installed wheel (sample → import → run with 2/0 workers, byte comparison → report → prune → train_smoke dry-run) on Windows and Linux.

## Known limitations

- Same as v0.7.0 (no second real-data pass or training-mAP evidence yet; SAM/diffusion are v1.0).
