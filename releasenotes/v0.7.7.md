# v0.7.7 — 2026-09-16

> v0.7.6 의 **퀵스타트 멱등 수정** + 작은 추가(COCO RLE · `bank merge --dedupe` · dry-run 기하 행). 전 과정 오프라인·로컬·CPU.

## 고친 것

- **퀵스타트(GUI '샘플 데이터' · `sample --quickstart`)를 같은 폴더에 두 번 돌리면 은행이 두 배로 쌓이던 것** — 같은 소스가 `-dup` 로 겹쳐 조명 의존 판정(유의성)까지 흔들렸습니다. 이제 퀵스타트 은행은 늘 새로 만듭니다. 0.7.6 이하로 두 번 누른 적이 있으면 그 폴더의 `bank/` 를 지우고 다시 누르세요.

## 새로운 기능

- COCO writer **`segmentation: rle`** — 비압축 RLE(pycocotools 규약). 조각·구멍이 있는 마스크도 무손실(폴리곤은 외곽 윤곽만).
- **`bank merge --dedupe`** — 같은 클래스에서 이미지·마스크 내용이 같은 소스는 한 번만(같은 원본을 두 은행에 임포트한 경우).
- `run --dry-run` 에 `geometry`(scale·rotate·flip) 행과 `per_class <클래스>` 행 · `bank ls --json` 에 `light_dir`.

## English

> A **quickstart idempotency fix** for v0.7.6 plus small additions (COCO RLE · `bank merge --dedupe` · geometry rows in dry-run). Fully offline, local, CPU-only.

## Fixed

- **Running the quickstart (GUI Sample… / `sample --quickstart`) twice into the same folder doubled the bank** — duplicated sources (`-dup`) also skewed the lighting-dependence test. The quickstart bank is now rebuilt from scratch. If you pressed it twice on 0.7.6 or earlier, delete that folder's `bank/` and run it again.

## New

- COCO writer **`segmentation: rle`** — uncompressed RLE (pycocotools convention); fragmented masks and holes are lossless (polygons keep only the outer contour).
- **`bank merge --dedupe`** — content-identical sources (image + mask) within a class are kept once (the same originals imported into two banks).
- `run --dry-run` prints a `geometry` row (scale · rotate · flip) and `per_class <class>` rows · `bank ls --json` includes `light_dir`.
