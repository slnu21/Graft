# v0.8.1 — 2026-09-17

> v0.8.0 뒤 같은 밤에 이어진 작은 기능들과 **첫 벤치마크 숫자**(`BENCHMARKS.md`). 전부 기본 off 또는 옵션 — 기존 레시피·골든·은행 결과는 그대로. 전 과정 오프라인·로컬·CPU.

## 새로운 기능

- **`BENCHMARKS.md`** — 공개 데이터로 잰 두 숫자. ① 박스→마스크 추정 IoU(1180 인스턴스). ② **합성 유/무 YOLO mAP**(MVTec metal_nut, real-train 클래스당 8장, 은행은 real-train 박스만): mAP50 **0.27 → 0.37**(`poisson-graft` 179장; scratch 0.17 → 0.35 · color 0.28 → 0.40), `dent-graft` 는 0.33(bent 에서 최고 0.36 → 0.40), 은행을 **`--mask-from hybrid`** 로 만들면 **0.46** — 시드 1개·CPU·40 epoch 이라 분산이 크다(첫 숫자, 결정 근거 아님). 재현 도구 `tools/train_mvtec_map.py`(별도 venv ultralytics).
- `source.redraw_on_empty`(기본 2) — 축소 뒤 마스크가 사라진 아주 작은 소스는 그 자리에서 다시 뽑아 이미지가 skipped 되지 않게. 실패했을 때만 난수를 더 쓰므로 기존 결과 불변.
- `source.single_class_per_image` — 한 이미지의 결함을 첫 결함의 클래스로 묶는다(MVTec writer 의 클래스 섞임 경고가 이 옵션을 가리킴).
- `geometry.tps: {points, jitter}` — thin-plate spline **휘어짐**(elastic 은 국소 잔물결, tps 는 전역 휘어짐). headless OpenCV 에 TPS 가 없어 numpy 로. 기본 jitter 0 = off.
- 레시피를 **다른 폴더에서 열어** 입력이 레시피 파일 기준으로 폴백되면 `output.root` 도 레시피 파일 기준으로(출력이 cwd 에 흩어지지 않게). `--out` 은 명시값 우선.
- `run --roi-cache N` — 대상당 ROI 캐시 크기(0 = 끔). 결과와 무관, 4K 대상 수백 장에서 메모리를 아낄 때.
- `dataset merge --dedupe-normals` — 같은 대상의 정상 이미지는 첫 루트 것만.
- GUI 상단 **'샘플 데이터' 옵션 대화상자**(모양·폴더·정상/결함 장수·크기·합성 장수·시드).
- `TESTING.md` 19항목 · `KNOWN-ISSUES.md` 2차 절차 v0.8.1 기준 · README 검수 탭 스크린샷(클래스 콤보·실측 CSV).

## English

> Small features that followed v0.8.0 the same night, plus the **first benchmark numbers** (`BENCHMARKS.md`). Everything is off by default or opt-in — existing recipes, goldens and banks produce the same output. Fully offline, local, CPU-only.

## New

- **`BENCHMARKS.md`** — two numbers measured on public data: ① box→mask estimation IoU over 1,180 instances; ② **YOLO mAP with vs. without synthetic data** (MVTec metal_nut, 8 real training images per class, bank built from those boxes only): mAP50 **0.27 → 0.37** with 179 `poisson-graft` images (scratch 0.17 → 0.35, color 0.28 → 0.40), 0.33 with `dent-graft` (best on bent, 0.36 → 0.40), and **0.46** when the bank is built with `--mask-from hybrid` — one seed, CPU, 40 epochs; the spread is large, so treat it as a first number, not a verdict. Reproduce with `tools/train_mvtec_map.py` (separate venv with ultralytics).
- `source.redraw_on_empty` (default 2) — a source whose mask vanishes after scaling is redrawn on the spot instead of skipping the image; extra randomness is consumed only on failure, so existing outputs are unchanged.
- `source.single_class_per_image` — all defects in an image follow the first defect's class (the MVTec writer's mixed-class warning now points here).
- `geometry.tps: {points, jitter}` — thin-plate-spline **bending** (elastic is local ripple, tps is global bending), in numpy since headless OpenCV lacks TPS. Default jitter 0 = off.
- When a recipe is opened from **another folder** and its inputs fall back to the recipe's folder, `output.root` follows too (no outputs scattered into the cwd). `--out` still wins.
- `run --roi-cache N` — per-target ROI cache size (0 = off); never changes results.
- `dataset merge --dedupe-normals` — keep a normal image once when several roots share the same target.
- GUI **Sample-data options dialog** (shape, folder, normal/defect counts, size, synthetic count, seed).
- `TESTING.md` (19 items), the KNOWN-ISSUES second-pass procedure updated to v0.8.1, a new Review-tab screenshot (per-class combo, measured CSV).
