# v0.8.0 — 2026-09-17

> 공개 데이터(MVTec AD metal_nut·screw·grid·bottle·hazelnut·carpet · Magnetic Tile · VisA · DTD)로 **KNOWN-ISSUES 2차 절차를 리허설**하며 나온 것들. 기본값·프리셋·골든·기존 은행은 그대로입니다. 받아서 확인하는 절차는 **`TESTING.md`**. 전 과정 오프라인·로컬·CPU.

## 새로운 기능

- **`anograft dataset merge a b … --out c`** — `run` 출력 폴더 여러 개(다른 프리셋·시드, 정리본 권장)를 한 학습셋으로. 파일 이름 `d<k>_` 접두어, 합성 행 index 재부여(사이드카 `merged_from`), `review.csv`·YOLO `labels/`·MVTec 레이아웃·COCO `annotations.json` 까지 병합, `merge.json` 요약. writer 형식이나 클래스 이름이 다르면 거부합니다(YOLO class id 가 어긋나므로).
- **배치 가능성 진단 v2** (`run --dry-run` fit 행 · 배치 로그 · 스튜디오 배치 카드) — 폭에 걸리는 건 **짧은 변**입니다. 가늘고 긴 스크래치가 링에 13/14 들어가는데 "불가"라던 판정이 사라지고, 행에 짧은/긴 변·근거(정렬 있음/없음)·µm/px 축척이 함께 나옵니다.
- **`source:` 경고** — 패치가 대상 자체와 맞먹는 클래스(MVTec `flip`, MT `uneven` 처럼 부품 전체 이상)는 ROI 를 넓혀도 답이 아니니 `source.classes` 로 빼라고. **`targets:` 경고** — 대상 폴더에 이미지 옆 마스크 PNG 가 있으면 마스크도 대상으로 뽑힌다고(.txt 목록 권고).
- 검수 탭 분포에 **클래스 콤보** — 외형 지표(대비·질감·선명도·조명 방향)를 한 클래스만 합성 vs 실제로, 제목에 그 클래스의 R(n). 리포트에도 실제 방향이 유의한 클래스별 조명 방향 히스토그램.
- 검수 '실제' 분포를 **실측 CSV** 로 — 검수 탭 `실측 CSV…` 버튼 · `dataset report --real-csv x.csv`. CSV 에 있는 열은 CSV 가, 없는 열은 은행이.
- **`bank import-yolo --mask-from hybrid`** (라벨 탭 자동 선택에도) — grabcut 사슬 결과가 저신뢰면 내접 타원으로. 공개 데이터 1180 인스턴스 벤치에서 IoU 중앙값 0.37 → 0.50, 실패율 0.43 → 0.21. **기본값은 그대로 `grabcut`** — 전환은 실데이터 2차 결과 뒤.
- **도구**: `tools/fetch_public_datasets.py`(표준 라이브러리만으로 MVTec 카테고리·DTD·Magnetic Tile·VisA 받기 + `--import`), `tools/bench_mask_from_box.py`(GT 마스크로 박스→마스크 추정 4+1 방법 IoU·confidence 벤치), 공개 데이터 레시피 `recipes/public-*.yaml` 3종.
- `KNOWN-ISSUES.md` **"결정 근거 — 공개 데이터 벤치"** 절 — 결정 대기 항목(grabcut/otsu · 저신뢰 임계)을 실데이터 없이 미리 읽는 표.

## English

> What came out of **rehearsing the KNOWN-ISSUES second-pass procedure on public data** (MVTec AD metal_nut/screw/grid/bottle/hazelnut/carpet, Magnetic Tile, VisA, DTD). Defaults, presets, goldens and existing banks are unchanged. The hands-on checklist is **`TESTING.md`**. Fully offline, local, CPU-only.

## New

- **`anograft dataset merge a b … --out c`** — combine several `run` outputs (different presets/seeds, pruned copies recommended) into one training set: `d<k>_` file prefixes, re-indexed synthetic rows (sidecar `merged_from`), merged `review.csv`, YOLO `labels/`, MVTec layout and COCO `annotations.json`, plus `merge.json`. Refuses outputs with a different writer format or class list (YOLO class ids would shift).
- **Placement-fit diagnostic v2** (`run --dry-run` fit rows · batch log · Studio placement card) — what has to fit the ROI width is the **short side**. Long thin scratches that landed 13/14 times in a ring are no longer reported as "impossible"; each row now shows short/long side, the reason (aligned or not) and the µm/px scale factor.
- **`source:` warning** — a class whose patches rival the target itself (MVTec `flip`, MT `uneven`: whole-part anomalies) should be excluded via `source.classes` rather than by widening the ROI. **`targets:` warning** — mask PNGs sitting next to target images would be sampled as targets too (use a .txt list).
- Review tab **per-class combo** for appearance metrics (contrast, texture, sharpness, lighting direction) — one class synthetic vs real, with that class's R(n) in the title; the report gains per-class lighting histograms for classes with a significant real direction.
- **Measured CSV as the "real" series** — Review tab `real CSV…` button · `dataset report --real-csv x.csv`; columns present in the CSV replace the bank, the rest still come from the bank.
- **`bank import-yolo --mask-from hybrid`** (also in the Label tab) — replaces a low-confidence grabcut-chain result with the inscribed ellipse. On a 1,180-instance public benchmark the median IoU rose 0.37 → 0.50 and the failure rate fell 0.43 → 0.21. **The default stays `grabcut`** until the real-data pass decides.
- **Tools**: `tools/fetch_public_datasets.py` (stdlib-only download of MVTec categories, DTD, Magnetic Tile, VisA, with `--import`), `tools/bench_mask_from_box.py` (box→mask IoU/confidence benchmark against GT masks), three public-data recipes `recipes/public-*.yaml`.
- `KNOWN-ISSUES.md` gains an **"evidence from public data"** section for the pending decisions (grabcut/otsu, low-confidence threshold).

## Fixed

- Synthetic sidecar `target.file` used Windows backslashes → posix, same as the manifest.

## Known limits

- The second real-data pass and training mAP remain unverified — follow `TESTING.md` and the KNOWN-ISSUES procedure.
- `dataset merge` copies normal images per root (a target present in two roots appears twice).
