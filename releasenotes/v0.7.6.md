# v0.7.6 — 2026-09-16

> v0.7.5 뒤의 **flip 모드 · per_class 편집 · 미리보기 ↯** 패치 — `flip` 이 `none/horizontal/vertical/both` 로 나뉘어 찍힘도 안전한 방향으로 뒤집을 수 있고, 클래스별 오버라이드를 스튜디오 표로 편집하며, 변형 카드가 조명 뒤집힘을 미리 표시합니다. 기존 레시피의 `flip: true/false` 는 그대로 읽히고 결과도 바이트 동일. 전 과정 오프라인·로컬·CPU.

## 새로운 기능

- **`geometry.flip`: `none · horizontal · vertical · both`** — `true/false` 는 `both/none` 으로 호환(rng 소비 동일 → 기존 레시피·골든 불변). 조명 경고는 **방향으로 판단**: 위/아래에서 오는 조명이면 `horizontal` 은 안전. `recipe init --auto-dent`·퀵스타트·기하 카드 ▶ 는 이제 **안전한 flip 까지 골라 준다**(위/아래 → horizontal, 옆 → vertical, 모르면 none).
- **기하 카드 `per_class` 편집 표** — 은행 클래스마다 적용 · 회전 lo/hi · flip(기본/없음/좌우/상하/둘 다). ▶ 버튼·`--auto-dent` 결과가 표에 보이고, 표에서 바로 고칩니다.
- **변형 카드 ↯ 조명 뒤집힘 의심** — 인스턴스의 하이라이트가 은행의 실제 방향과 90° 넘게 다르면 캡션 ↯ + 툴팁(검수 탭 필터를 미리보기에서).
- `bank ls` `lightR` 열에 `*`(유의한 조명 의존) · `bank preview`/은행 탭 화살표(v0.7.4 부터) · 검수 탭 **표시된 것 전부 반려**(필터 뒤 일괄).
- `tools/train_smoke.py --synthetic a --synthetic b …` — 출력 여러 개(다른 프리셋·시드)를 한 학습셋으로.
- README "조명 의존 결함 한 바퀴" 표 · CI 가 ring 퀵스타트 → check → dry-run → run --report → prune --drop-flipped 를 설치된 wheel 로 돈다.

## English

> A **flip modes · per-class editor · preview ↯** patch after v0.7.5 — `flip` splits into `none/horizontal/vertical/both` so dents can be mirrored in the safe direction, per-class overrides get a table in the Studio, and variant cards flag flipped lighting before you run. Existing recipes with `flip: true/false` load unchanged and produce identical output. Fully offline, local, CPU-only.

## New

- **`geometry.flip`: `none · horizontal · vertical · both`** — `true/false` map to `both/none` (same RNG budget → existing recipes and goldens unchanged). The lighting warning now **reasons about direction**: with light from above/below, `horizontal` is safe. `recipe init --auto-dent`, the quickstart and the geometry-card ▶ button **pick the safe flip for you** (above/below → horizontal, side → vertical, unknown → none).
- **Per-class table in the geometry card** — enable · rotation lo/hi · flip (default/none/horizontal/vertical/both) per bank class. What ▶ and `--auto-dent` wrote shows up here and can be edited in place.
- **Variant card ↯ flipped lighting** — when an instance's highlight differs from the bank's real direction by more than 90°, the card gets ↯ and a tooltip (the Review filter, in the preview).
- `bank ls` marks significant lighting-dependent classes with `*` · lighting arrows on `bank preview` / Bank-tab tiles (since v0.7.4) · Review tab **Reject all shown** (bulk after a filter).
- `tools/train_smoke.py --synthetic a --synthetic b …` — merge several outputs (different presets/seeds) into one training set.
- README "the lighting-dependent loop" table · CI runs the ring quickstart → check → dry-run → run --report → prune --drop-flipped on the installed wheel.

## Changed

- Preset YAML flip vocabulary is now `both`/`none` (same values). `DENT_OVERRIDE` is `flip: none`; the automatic paths choose `horizontal` when the light direction allows it.

## Known limitations

- No second real-data pass or training-mAP evidence yet (use the procedure and result table in `KNOWN-ISSUES.md` with this version). SAM/diffusion are v1.0.
