# v0.1.0 — 2026-09-14

> 첫 릴리스. 샘플 데이터로 엔드투엔드 검증했고, **보유 실데이터·MVTec AD·학습 1 epoch은 아직 미검증**입니다. 전 과정 오프라인·로컬·CPU.

## 새로운 기능

- **결함 은행** — 보유 YOLO 라벨(박스·폴리곤)에서 결함을 모읍니다(`bank import-yolo`). 박스만 있으면 마스크를 추정하고(GrabCut → Otsu → 타원 → 사각 폴백) 출처를 `mask_origin`으로 기록합니다. 마스크 PNG 쌍(`import-pairs`)·MVTec AD 로컬 사본(`import-dataset mvtec-ad`)도 같은 은행이 됩니다. `bank ls`(클래스별 소스 수·정확/추정) · `bank preview`(추정 마스크 그리드).
- **7단계 파이프라인 + 프리셋 4종** — `소스 → 기하 → 배치 → 블렌딩 → 조화 → 열화 → 정답 마스크`. 블렌딩 paste · alpha · Poisson · multiband, 조화 stats · Reinhard · 히스토그램 매칭, 배치 허용 영역(ROI) 기본 켜짐. `poisson-graft`(기본) · `multiband-graft` · `alpha-paste` · `hard-paste`. 레시피는 YAML 한 장, `anograft methods`가 선택지를 보여줍니다.
- **재현 가능한 출력** — 이미지 + GT 마스크 + 사이드카 JSON(소스 id·변환·좌표·시드·파이프라인 해시) + `manifest.csv`. 같은 레시피·시드면 워커 수와 무관하게 바이트 동일(`run --workers N`). YOLO writer가 `labels/*.txt`·`data.yaml`을 덧붙여 기존 학습셋에 그대로 합칠 수 있습니다.
- **미리보기** — `preview --index i`(원본|합성|GT), `--compare-methods blend|harmonize`(같은 시드로 방법 전부, 결함 주변 확대).
- **GUI 스튜디오** — 대상 레일 · 프리셋/시드 · A/B 와이프(GT·ROI 오버레이·줌) · 시드 변형 6장 · 파이프라인 7카드(방법 콤보 + 단계 썸네일) · 레시피 열기/저장. 미리보기는 긴 변 1024 축소본입니다.
- **Windows zip** — `anograft-0.1.0-win64.zip`을 풀면 파이썬 없이 `anograft.exe`(CLI)·`anograft-gui.exe`(GUI)가 바로 실행됩니다(설치·관리자 권한 없음, 73 MB).
- **샘플 데이터** — `anograft sample --out samples/metal`로 브러시드 메탈 + scratch/pit/stain YOLO 세트를 만들어 데이터 없이 5분 안에 한 바퀴 돌릴 수 있습니다.
- `tools/train_smoke.py` — 출력을 기존 YOLO 셋과 합쳐(`ultralytics` 별도 설치 시) 1 epoch 스모크.

## 알려진 한계

- 보유 실데이터·MVTec AD 실제 사본·학습 1 epoch은 미검증(샘플로만). GUI는 스튜디오 탭만 동작합니다.
- 프리셋 기본값(Poisson NORMAL, 조화 strength 0.3~0.5)은 샘플 은행에서 "결함이 옅어지는 정도"를 재서 정했고 학습 성능 근거는 아직 없습니다.
- 재현은 같은 OS·OpenCV 부버전 범위(zip끼리는 동일).

## English

> First release. Verified end to end on the bundled sample set; **real customer data, MVTec AD and a training epoch are not yet verified.** Fully offline, local, CPU-only.

## New

- **Defect bank** — collect defects from your YOLO labels (boxes/polygons) with `bank import-yolo`; boxes get an estimated pixel mask (GrabCut → Otsu → ellipse → rect fallback) with provenance in `mask_origin`. Mask PNG pairs (`import-pairs`) and a local MVTec AD copy (`import-dataset mvtec-ad`) land in the same bank. `bank ls` (per-class counts, exact/estimated) · `bank preview` (estimated-mask grid).
- **7-stage pipeline + 4 presets** — `source → geometry → placement → blend → harmonize → degrade → gt-mask`. Blend: paste · alpha · Poisson · multiband; harmonize: stats · Reinhard · histogram matching; placement ROI on by default. `poisson-graft` (default) · `multiband-graft` · `alpha-paste` · `hard-paste`. One YAML recipe; `anograft methods` lists the choices.
- **Reproducible output** — image + GT mask + sidecar JSON (source id, transform, coordinates, seed, pipeline hash) + `manifest.csv`. Same recipe and seed ⇒ byte-identical regardless of worker count (`run --workers N`). The YOLO writer adds `labels/*.txt` and `data.yaml` so the output merges straight into an existing training set.
- **Preview** — `preview --index i` (original | synthetic | GT) and `--compare-methods blend|harmonize` (every method at the same seed, zoomed on the defect).
- **GUI Studio** — target rail, preset/seed, A/B wipe (GT/ROI overlays, zoom), six seed variants, seven pipeline cards (method combo + stage thumbnails), recipe open/save. Previews run on a 1024 px downscale.
- **Windows zip** — unzip `anograft-0.1.0-win64.zip` and run `anograft.exe` (CLI) / `anograft-gui.exe` (GUI) with no Python, installer or admin rights (73 MB).
- **Sample data** — `anograft sample --out samples/metal` generates a brushed-metal YOLO set (scratch/pit/stain) for a five-minute first run without any data.
- `tools/train_smoke.py` — merges the output into an existing YOLO set and runs one `ultralytics` epoch (ultralytics installed separately).

## Known limitations

- Not yet verified on real data, an actual MVTec AD copy, or a training epoch (sample set only). Only the Studio tab of the GUI is functional.
- Preset defaults (Poisson NORMAL, harmonize strength 0.3–0.5) were chosen by measuring defect fading on the sample bank; there is no training-accuracy evidence yet.
- Reproducibility holds within the same OS and OpenCV minor version (zip builds match each other).
