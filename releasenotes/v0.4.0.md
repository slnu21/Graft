# v0.4.0 — 2026-09-15

> CPU 알고리즘 확장 릴리스. **은행(라벨링 결함) 없이도** 정상 이미지만으로 합성이 돌고, 배치가 결·모서리 방향을 따르며, 출력이 anomalib 에도 바로 들어갑니다. 여전히 **샘플 데이터로만 검증**했고 실데이터·표준셋 실제 사본·학습 1 epoch 은 미검증입니다. 전 과정 오프라인·로컬·CPU.

## 새로운 기능

- **은행 없이 시작** — `self-cut`(CutPaste·Scar: 대상 자신에서 잘라 붙임 + 색 지터) · `perlin-texture`(DRAEM: 펄린 노이즈 마스크 + 텍스처) 소스. `anograft recipe init --preset self-cut --targets <정상 폴더>`(`inputs.bank: null`)만으로 `run`. 이상 탐지 이진 학습용 클래스 하나.
- **구조 정합 배치** `placement: structure-aware` — 그래디언트가 큰 곳(모서리·각인)을 선호하고(`prefer` edges/flat/uniform), 결함의 긴 축을 자리의 결·에지 방향에 맞춥니다(`align` along/across, `jitter_deg`). 스크래치가 브러시 결을 따라 눕고 칩이 모서리에 생기는 부품에. 프리셋 `structure-aware-graft`.
- **GrabCut ROI** `roi: grabcut` — Otsu 로 전경/배경이 안 갈리는 무광·그림자 부품. rect/otsu 초기화, 긴 변 1024 작업 해상도, 같은 파일이면 같은 ROI.
- **카메라 열화 추가** — `degrade: camera`에 모션 블러(`motion_blur_px`) · 비네팅(`vignette`) · 감마(`gamma`). 전부 기본 off(레시피에서 범위를 주면 켜짐), 기존 레시피 결과는 그대로.
- **VisA 어댑터** — `anograft dataset info visa` → `bank import-dataset visa <VisA>/<category>`. 결함 유형 세분이 없는 셋이라 클래스 `anomaly` 하나. 로컬 사본 읽기만(CC BY-NC-SA).
- **MVTec 형식 writer** `output.writer: {format: mvtec, category: …}` — 정본 위에 anomalib 이 그대로 읽는 `mvtec/<category>/{train/good, test/good, test/<class>, ground_truth/<class>}` 레이아웃을 추가로 씁니다. 정상은 `test_normal_ratio` 로 train/test 분할(시드로 결정적).
- `blend.alpha.opacity`(DRAEM β) · `preview --compare-methods source`.

## 바뀐 것

- `placement` 블록의 `method:` 를 생략하면 `sampled` 로 읽습니다(v0.1 레시피 호환). 파이프라인 카드에서 배치 method 를 바꿔도 ROI 설정이 유지됩니다.
- 프리셋 7종(`poisson-graft` · `multiband-graft` · `alpha-paste` · `hard-paste` · `self-cut` · `perlin-texture` · `structure-aware-graft`), `anograft methods` 24 선택지 전부 사용 가능.

## 알려진 한계

- 실데이터·MVTec AD/VisA 실제 사본·anomalib/ultralytics 학습은 미검증(샘플 + 가짜 트리 픽스처로만).
- `structure-aware` 의 `prefer: edges` 는 부품 외곽으로 쏠립니다 — 결만 따르게 하려면 `prefer: uniform`.
- `mvtec` writer 는 이미지당 클래스 하나 — 여러 클래스가 섞이면 면적이 큰 쪽 폴더에 두고 경고합니다(`defects_per_image: [1, 1]` 권장).
- GUI 는 스튜디오 탭만(라벨 탭은 v0.5). 재현은 같은 OS·OpenCV 부버전 범위.

## English

> CPU-algorithm expansion. Synthesis now runs **without a defect bank** (normal images only), placement follows grain/edge direction, and output drops straight into anomalib. Still **verified on the bundled sample set only** — real data, actual MVTec AD/VisA copies and a training epoch are unverified. Fully offline, local, CPU-only.

## New

- **Start without a bank** — `self-cut` (CutPaste/Scar: cut from the target itself + colour jitter) and `perlin-texture` (DRAEM: Perlin-noise mask + texture) sources. `anograft recipe init --preset self-cut --targets <normals>` (`inputs.bank: null`) then `run`. Single class for binary anomaly training.
- **Structure-aware placement** `placement: structure-aware` — prefers high-gradient spots (edges, engravings; `prefer` edges/flat/uniform) and aligns the defect's long axis to the local grain/edge direction (`align` along/across, `jitter_deg`). For parts where scratches follow the brushing and chips sit on edges. Preset `structure-aware-graft`.
- **GrabCut ROI** `roi: grabcut` — for matte or shadowed parts Otsu cannot split. rect/otsu init, 1024 px working resolution, same file ⇒ same ROI.
- **More camera degradation** — `degrade: camera` gains motion blur (`motion_blur_px`), vignetting (`vignette`) and gamma (`gamma`). All off by default; existing recipes are unchanged.
- **VisA adapter** — `anograft dataset info visa` → `bank import-dataset visa <VisA>/<category>`. VisA has no defect-type split, so one class `anomaly`. Reads a local copy only (CC BY-NC-SA).
- **MVTec-format writer** `output.writer: {format: mvtec, category: …}` — adds the `mvtec/<category>/{train/good, test/good, test/<class>, ground_truth/<class>}` layout anomalib reads, on top of the canonical output. Normals split train/test by `test_normal_ratio` (seeded, deterministic).
- `blend.alpha.opacity` (DRAEM β) · `preview --compare-methods source`.

## Changed

- A `placement` block without `method:` is read as `sampled` (v0.1 recipes keep working). Switching the placement method in the pipeline card keeps the ROI settings.
- Seven presets (`poisson-graft` · `multiband-graft` · `alpha-paste` · `hard-paste` · `self-cut` · `perlin-texture` · `structure-aware-graft`); all 24 choices in `anograft methods` are usable.

## Known limitations

- Unverified on real data, actual MVTec AD/VisA copies, and anomalib/ultralytics training (sample set and fake-tree fixtures only).
- `structure-aware` with `prefer: edges` gravitates to the part outline — use `prefer: uniform` to only follow the grain.
- The `mvtec` writer keeps one class per image; mixed-class images go to the larger instance's folder with a warning (`defects_per_image: [1, 1]` recommended).
- GUI: Studio tab only (the Label tab lands in v0.5). Reproducibility holds within the same OS and OpenCV minor version.
